# cs-roadmap
# 我的计算机升学路线图

## 🎯 终极目标
- 港大 (HKU) / 港中文 (CUHK) 计算机硕士 或 北大深研院

## 📚 本学期核心指标
- **GPA目标**：稳住核心课（高数、C语言），争取 3.5+ / 4.0 （或按你们学校满分制换算）
- **英语目标**：四级备考启动。本学期背完四级核心词汇，期末真题模考争取 **500分以上**（底线425分）
- **编程目标**：吃透C语言基础，能独立用循环写小工具（如累加求和、九九乘法表）

## 👨‍💻 本周具体任务（先不碰LeetCode）
1. [ ] 用 C 语言写一个 1 到 100 的累加求和程序，并跑通。
2. [ ] 注册 LeetCode 账号，看一遍“两数之和”的题目描述，理解它想干嘛。
3. [ ] 每天背 40 个四级单词

 ## 📅 下周任务（Week 2）
1. [ ] **C语言实战**：用 `for` 循环和 `if` 判断，写一个“猜数字”游戏（程序随机生成1-100的数，用户输入去猜，程序提示“大了”或“小了”，直到猜中）。
2. [ ] **LeetCode 起步**：在网站上点击“两数之和”的“提交”，把你学到的双重循环敲进去，无论对错，体验一次“提交代码”的感觉。
3. [ ] **四级词汇**：背完四级高频词汇的前 5 个 List（每天大概 40-50 个，周末复习）。
4. [ ] **专业课**：下一次上 C 语言课，下课拦住老师，问一个关于“循环嵌套”或者“数组”的问题（问什么都可以，重点是混脸熟）。

## 🛠️ 长期习惯
- 每次上完专业课，把代码作业传到这里（学 Git 操作）。
- 遇到不会的先去问 AI 或查资料，实在不行再去问老师（混脸熟）。
